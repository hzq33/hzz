## 2. 口吻模仿的需求

口吻模仿要的是**特定角色的真实对话样本**，用于学习该角色的说话风格：
- 语气词（"的说""啊""呢"等口癖）
- 称谓习惯（"哥哥大人""八奈见同学"）
- 句式特征（长短句、省略、倒装）
- 情绪模式（吐槽、温柔、傲娇）

所以对话检索需要满足：**每个角色 ≥30 条代表性对话，跨越不同场景和情绪**。

## 3. 改进方案

### 3.1 配额调整

```yaml
# 当前
quotas:
  main: 50       # 主力角色
  supporting: 40 # 配角
  extra: 10      # 龙套

# 口吻模仿用
quotas:
  main: 80       # 更多样本
  supporting: 60
  extra: 30      # 龙套也要够（否则无法模仿）
  min_per_character: 30  # 硬底线：角色够 30 条才停
```

### 3.2 说话人过滤强化

在 `sanitize_turns` 之后加一道**碎片过滤**：
```python
# 说话人长度 > 10 或含助词/标点 → 丢弃（LLM 的错输出）
if len(speaker) > 10 or any(kw in speaker for kw in ['也','的','了','是','在','就','把','被']):
    reject
```

### 3.3 对话风格标注

抽取时让 LLM 输出一个 `style` 字段（可选），标注台词的口吻特征：

```json
{"speaker": "八奈见杏菜", "content": "草介这个骗子！", "style_tags": ["愤怒", "娇嗔"]}
```

prompt 加规则：`10. 每条对话标注 style_tags（可选）：吐槽/撒娇/愤怒/温柔/傲娇/自嘲/严肃/好奇/兴奋/无奈 选 0-2 个。`

后处理用正则/LLM 二次打标也可以，但抽取时打标效率更高。

### 3.4 章节覆盖策略

当前 `min_chapter_coverage_main: 0.3` —— 主角色覆盖 30% 章就停。口吻模仿需要跨场景多样性：
```yaml
min_chapter_coverage_main: 0.5   # 提高到 50%
chapter_diversity: true           # 新增：优先选未覆盖的章节
```

### 3.5 非台词过滤

当前 prompt 规则 4 "不要把无引号的旁白/内心独白抽成对话"——但 LLM 经常漏。加硬规则：

```python
# 台词内容必须来自「」『』"" '' 包裹的原文
# 若 content 在原文中不在引号内 → 标记 low confidence → 丢弃
```

### 3.6 角色范围限定

口吻模仿只关心**有角色卡的角色**（用户建过卡的要优先覆盖）。在 quota tracker 里加权重：
```python
priority_boost: ["利姆露", "八奈见杏菜", "温水和彦", ...]  # 角色卡里的角色
```

## 4. 实施优先级

| 优先级 | 改动 | 影响 | 复杂度 |
|--------|------|------|--------|
| P0 | 碎片说话人过滤（3.2） | 立刻清除脏数据 | 低 |
| P0 | 配额上调（3.1） | 增加对话量 | 低 |
| P1 | 风格标注（3.3） | 口吻模仿价值高 | 中 |
| P2 | 章节覆盖（3.4） | 多样性 | 低 |
| P3 | 非台词过滤（3.5） | 精度 | 中 |
| P3 | 角色优先（3.6） | 定向覆盖 | 低 |

## 5. 验证方式

改完后，针对败犬 vol01-02 跑一次对话抽取：
- 检查每个角色的对话数（是否达 quota）
- 检查碎片说话人比例（应为 0%）
- 抽样检查对话内容质量（是否真是角色台词）
